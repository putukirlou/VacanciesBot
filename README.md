# VacanciesBot

VacanciesBot - это бот который представляет собой программное решение, разработанное специально для фрилансеров и специалистов, которые ищут заказы на платформе Habr Freelance. Он осуществляет постоянный мониторинг всех новых заказов на сайте, а затем передает самые актуальные и интересные предложения своим пользователям.

Благодаря уникальной системе фильтрации и анализа данных, бот способен выделять заказы по различным категориям: от дизайна и разработки до копирайтинга и маркетинга. Пользователь может настроить параметры поиска в соответствии со своими навыками, интересами и предпочтениями, чтобы получать только те заказы, которые ему действительно подходят.

Основная цель бота - помочь фрилансерам экономить время на поиск заказов и сосредоточиться на выполнении проектов. Благодаря персонализированным уведомлениям и рекомендациям, пользователь всегда будет в курсе новых возможностей на рынке фриланса и сможет максимально эффективно использовать свои профессиональные навыки.

Присоединитесь к боту прямо сейчас и начните получать персонализированные уведомления о заказах на Habr Freelance. Доверьте свои поиски нашему боту и увидьте, как легко и удобно становится находить интересные проекты и зарабатывать деньги в мире фриланса! 🤖💼✨

## Структура проекта

1) main.py - главный файл
2) widgets.py - файл содержащий настройки и стили кнопок
3) support.py - файл содержащий класс функций фильтров
4) requirements.txt - зависимости проекта
5) instruction.txt - текстовый файл с инструкцией по использованию


## Как пользоваться программой

1. Установите необходимые зависимости, запустив команду:
   
   pip install -r requirements.txt
   

2. Запустите программу:
   1) используя следующую команду:
      python main.py
